# Water Spring Background Image

## Image Location

The water spring image should be saved at:
`public/images/water-spring-bg.jpg`

## How to Add the Image

1. **Save the uploaded image** (the water spring photo with rocks and flowing water)
2. **Rename it to**: `water-spring-bg.jpg`
3. **Move it to**: `public/images/` folder

## Current Setup

The Home page is already configured to use this image as a background with:

- Semi-transparent dark overlay for text readability
- Glass-morphism effect on feature cards
- White text with drop shadows
- Beautiful cyan/blue color scheme that complements the water theme

## Alternative: Use a URL

If you prefer to use an external image URL instead, update line 8 in `src/pages/Home.tsx`:

```tsx
style={{ backgroundImage: 'url(YOUR_IMAGE_URL_HERE)' }}
```

## Recommended Image Specifications

- **Format**: JPG or WebP
- **Dimensions**: 1920x1080px or larger
- **File size**: Under 500KB (optimized for web)
- **Subject**: Water/nature theme (current: spring water flowing over rocks)
